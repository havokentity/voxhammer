# maps/

The three sandbox maps (TOML scene + binary voxel payload), landing in M7:

1. **City Block** — multi-story buildings, parked cars, gas stations.
2. **Industrial Yard** — cranes/excavators (PhysX articulations), containers, fuel tanks.
3. **Suburban Cul-de-Sac** — single-family houses, fences, school bus.

Free play, full tool loadout, optional Lua challenges. No narrative.
